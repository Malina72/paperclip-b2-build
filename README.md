# Paperclip B3 isolated candidate build

Official upstream v2026.1117.0/c0f132898d2a2677312d8c72096187b27a3d9a38 plus the reviewed B2 JavaScript fixes and eight compatible Rust lock-only patch updates. Existing application/Rust source and manifests are unchanged. Exact versions, source hashes, official package checksums and review-policy hash are in pins.json. The combined patch is patches/B3.patch; B2.patch is retained for traceability.

Manual standard free public GitHub Ubuntu24.04 runner only. One isolated Docker29.10.0 daemon/config/socket/data directory, default seccomp/AppArmor, no privileged or unconfined builder. Preflight requires4CPU/about16GB RAM,48GiB free disk, containerd store and digest-bound OCI attestation support. No paid runners, Actions artifact/cache storage or fallback. No owner workspace, credentials, deployment data or other projects are build inputs.

Before the production build, the same native production rlibs undergo six offline TLS tests: trusted and unknown roots, wrong hostname, corrupted signature, expiry and removal of emSign ECC Root CA-G3. Test credentials are generated only in a build-only branch, never copied into production. Active Cargo tree must exclude optional QUIC. Tests invoke only a standalone fixture, never Paperclip or Codex. No cryptographic architecture is changed.

After build: inspect all image layers, exact runtime/native versions, Ubuntu packages, secret-like matches, SPDX/SLSA bindings, current npm/Trivy/RustSec findings and copied Cargo.lock identity. Unknown findings or changed reviewed inputs stop publication. A separate bounded Node/library fixture overrides the entrypoint:512MiB/no swap/1CPU/64PIDs, read-only root, no host mounts, network none, no capabilities, no-new-privileges, AppArmor/seccomp. It tests actual kernel limits, Sharp and bounded compressed HTTP/error/routing behavior. It does not start the application.

security-review.json retains conditional findings instead of globally suppressing them. The remaining crypto-bigint issue concerns the forbidden AWS/SigV4A provider; its incompatible0.5->0.7 upgrade is not applied. Two archived-package notices are informational. QUIC lock records are excluded only if production graph confirms absence. Current JavaScript and OS findings have per-consumer conditions; no claim of zero CVEs is made. Native supplier versions and ConanCenter metadata screening do not guarantee exhaustive C/C++ binary coverage.

Package-owned executables/SDKs remain. Legacy codex_local has unsafe bypass defaults and is forbidden. Only a separately qualified remote native Codex profile is proposed; runtime restrictions and authorization still need negative tests. A candidate publication never authorizes application/executor startup, accounts, agents or deployment.

BuildKit SBOM/provenance bind image digests; an independent publisher identity signature is not claimed. Pinned inputs are rebuildable but byte-identical output has not been demonstrated. MIT attribution from upstream is retained.
